# About Rise-X & the EOP

**Rise-X** is a deep-tech SaaS company that created the **Ecosystem Orchestration Platform (EOP)** — a blockchain-backed, multi-party workflow platform for cross-organisation collaboration.

**What it replaces:** Emails, spreadsheets, and siloed apps that break down when multiple companies need to collaborate on a shared process.

**How it works:** All parties (buyer, supplier, port authority, inspector, etc.) work on the same platform in real time. Workflows are built with no-code tools and secured with role-based access controls so each party sees only what they're permitted to. A common ledger (blockchain) records all interactions for auditability and data integrity.

**Core value proposition:**
- **Multi-party collaboration** — multiple organisations on a single shared workflow, each with their own tasks
- **Transparency** — shared data = fewer disputes, one source of truth
- **No-code workflow builder** — design and deploy workflows without engineering
- **Blockchain-backed audit trail** — immutable record of all transactions
- **Automation** — reduce manual errors, delays, and repetitive tasks
- **API integration** — connects to existing industry-specific systems

**Target industries:** Carbon-intensive sectors — Transportation & Logistics, Energy & Resources (oil, gas, LNG, lithium, mining), Maritime & Bunkering, Defense & Security, Agriculture, and general Supply Chain.

**Notable deployments:** Marine LNG fuel trading (QuayChain, launched Singapore 2019), multi-party fuel ordering with Woodside (SmartFlow), commodity trading with Mercuria Energy Group (ADP).
